# Physio Study App

A lightweight, installable clinical study companion for physiotherapy students and clinicians.

## Features

- SOAP clinical notes with local autosave
- Regional range-of-motion charts with side-to-side comparison
- Joint mobility grading and end-feel documentation
- Structured patient assessment checklist and progress summary
- Offline-ready Progressive Web App (PWA)
- Responsive layout for phone, tablet, and desktop

## Live site

[Open Physio Study](https://sanjayphysics1104-jpg.github.io/Physio-study-app/)

Assessment information is stored only in the browser's local storage. The app is intended for education and documentation support and does not replace professional clinical judgment.
